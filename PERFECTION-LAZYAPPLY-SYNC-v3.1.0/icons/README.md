# ATS PERFECTION LazyApply Sync Icons

This folder should contain the following icon files:

- `icon16.png` - 16x16 pixels
- `icon48.png` - 48x48 pixels  
- `icon128.png` - 128x128 pixels

## Quick Setup

Copy icons from the main extension:

```bash
cp ../PERFECTION/icons/*.png ./icons/
```

Or from another working extension:

```bash
cp "../PERFECTION UPDATE 3.0 - FIX 27-01-26/icons/"*.png ./icons/
```
