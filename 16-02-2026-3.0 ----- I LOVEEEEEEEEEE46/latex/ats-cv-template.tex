% Compile with pdflatex (Overleaf: default compiler works as-is).
% Paste the tailored text from the extension into the marked sections.
%
% READ THIS FIRST: LaTeX IS NOT AUTOMATICALLY "BETTER" FOR ATS.
%
% A LaTeX CV is a PDF, and ATS parse DOCX more reliably than any PDF,
% which is why the extension attaches the DOCX. What people admire in
% the famous LaTeX templates -- one column, no tables, no graphics,
% plain headings -- is layout, and the extension's DOCX already has all
% of it. Worse, a DEFAULT LaTeX build actively damages parsing in three
% ways this file turns off:
%
%   LIGATURES. pdflatex fuses fi/ffi/fl into single glyphs, so
%   "efficient" can extract as "e cient" and never match a keyword.
%   \DisableLigatures stops the fusing; \pdfgentounicode maps every
%   glyph back to real characters for the extractor.
%
%   HYPHENATION. LaTeX justifies by breaking words across lines, and a
%   keyword split "engi-neering" matches nothing. hyphenat [none] plus
%   \raggedright means no word is ever broken.
%
%   ENCODING. Without fontenc T1, accented characters extract as
%   composed pairs. Fixed below.
%
% Everything else mirrors the DOCX the extension generates: the same
% section order the parsers expect, the same navy accent restricted to
% the name and headings, pipes only in the contact line (parsers regex
% that line; they SPLIT the skills lines, so skills stay comma-only),
% no tables, no text boxes, no icons, no header/footer, no page number.
% =====================================================================
\documentclass[11pt,a4paper]{article}

% ---- text-extraction correctness (the part an ATS actually sees) ----
\input{glyphtounicode}
\pdfgentounicode=1
\usepackage[T1]{fontenc}
\usepackage[utf8]{inputenc}

\usepackage{microtype}
\DisableLigatures{encoding = *, family = *}
\usepackage[none]{hyphenat}

% ---- layout: one column, generous line length, no decoration ----
\usepackage[a4paper,left=1.7cm,right=1.7cm,top=1.4cm,bottom=1.4cm]{geometry}
\usepackage{enumitem}
\usepackage{xcolor}

\definecolor{rulecol}{HTML}{BDC7D9}% the heading rule

\pagestyle{empty}
