## Installation

1. Open Chrome and navigate to `chrome://extensions`
2. Enable "Developer mode"
3. Click "Load unpacked"
4. Select this folder

## Usage

1. Navigate to any supported ATS platform (Greenhouse, Workday, etc.)
2. The extension auto-detects job listings and triggers tailoring
3. CV and Cover Letter are generated with 100% keyword match
4. Files are automatically attached to application forms

## Banned Words (Never Used)

- orchestrated, championed, pioneered, helmed, realm
- comprehensive, demonstrating, showcasing, spearheaded
- meticulous, proven ability, proven track record
- leverage, leveraging, utilize, utilizing
- highly motivated, dynamic, synergy, cutting-edge

## Approved Alternatives

- Led, Directed, Established, Built, Created
- Thorough, Extensive, Complete (instead of comprehensive)
- Used, Employed, Applied (instead of leverage/utilize)
- Field, Sector, Industry (instead of realm)
